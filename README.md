# Cancer-detection-metabolomics-machine-learning
Cancer detection metabolomics machine learning.

This dataset is from the following publication: Metabolomic machine learning predictor for diagnosis and prognosis of gastric cancer : https://rdcu.be/Qv4bpEPZ8Wta/. The authors presented an early cancer detection assay for gastric cancer using metabolomics data from gastric cancer patients compared to matched controls.
